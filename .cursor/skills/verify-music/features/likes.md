# Likes

## Sub-features

Add, remove, merge Spotify likes, persist local choices.

## How to get to it (user POV)

Use a heart button in search, Liked songs, an album, or another song list.

## Driving it with Playwright

Run npm run verify:search. Like a search hit, close search, reload, then remove it.

## Gotchas

Local unlike hides a Spotify like in this app. It does not update Spotify.
